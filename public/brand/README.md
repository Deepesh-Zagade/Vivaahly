# Vivaahly logo assets

The master mark is traced from the approved Vivaahly reference artwork. It uses two broad, tapered strokes meeting at a single vertex.

| File | Use |
| --- | --- |
| `vivaahly-mark.svg` | Default standalone mark used by the application header |
| `vivaahly-mark-monochrome.svg` | Single-colour printing and constrained surfaces |
| `vivaahly-mark-reversed.svg` | Standalone mark on burgundy or other dark backgrounds |
| `vivaahly-logo.svg` | Primary horizontal lockup |
| `vivaahly-logo-monochrome.svg` | Single-colour horizontal lockup |
| `vivaahly-logo-reversed.svg` | Horizontal lockup on dark backgrounds |
| `vivaahly-favicon.svg` | Padded square application and social icon |

The lockup SVGs keep the wordmark as editable text using `EB Garamond` with a Georgia fallback. The application renders its wordmark separately through the shared `Brand` component so the locally loaded web font remains authoritative.

Primary sampled colours from the approved reference:

- Wordmark: `#5A0D22`
- Burgundy stroke: `#701A31` to `#5B1329`
- Terracotta stroke: `#D77960` to `#AE5540`
- Warm ivory: `#FFF8F4`
